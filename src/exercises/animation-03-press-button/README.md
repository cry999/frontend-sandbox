# アニメーション03：押すと沈むボタン

進捗：レビュー合格（2026-10-29）。全30問の第3問。目安30〜60分。

## 到達点

- 固定した外側のbuttonでhover・focus-visible・activeを受け取り、内側のspanの面を動かした。ブラウザ標準の背景と余白を取り除き、裏側の灰色が見える問題を解消した。
- 押下時に96%へ縮小し、約2px沈み、影が浅くなる。通常時に120ms・ease-outのtransitionを置いて、離すと復帰する。変形の順序により実際の下移動は1.92pxで、約2pxという条件を満たす。
- ブラウザで通常時の面・外側とも45px、Space長押し時の縮小と影、外側の寸法維持、離した後の復帰を確認。左右端・下端の長押しクリックは各1回反応し、範囲外へ出て離したときは回数が増えず変形も残らない。
- Tabの3pxの輪・3pxの隙間、Space長押し中の輪、Enter・Spaceの各1回の反応を確認。360px・390px幅で文字と輪の欠け・横はみ出しなし。
- 動きを減らす場合はtransitionと変形をなくし、押下の背景色と影を残すCSSを確認。利用可能な操作では設定を再現できず、有効時の実動作は未確認。

- ユーザーの観察：「遠近法？」。面の縮小から奥へ動く印象、浅い影から下の面へ近づく印象を感じると整理した。
- 苦戦した点：button標準の背景・余白、メディアクエリのnotと括弧の間のスペース、動きを減らす条件でも影を変えるための指定位置。

## 目的

押している間だけ面を縮め、影を浅くして、押した感触を作る。前回学んだ「押せる範囲と動く面を分ける」構造を使い、端で押しても安定し、離すと元へ戻るボタンを作る。

前回の合格コミットは`91c58ea`。前回は「影があることによる目の錯覚」と観察した。今回は影を浅くしたときの印象を比べる。

`npm run dev`で表示されるURLを開く。今回の比較画面は上部にあり、過去の課題は下の折りたたみで確認できる。操作回数は見本と実装欄で別々に数える。

## まず観察する

1. ポインターを重ねただけの状態と、押し続けた状態を比べる。面の大きさ、位置、影の深さを別々に観察する。
2. 長押しから離して、元の大きさと影へ戻るところを見る。すばやく何度か押した場合も試す。
3. 左右の端で押し続ける。縮んでも反応が途切れず、押す・戻るを繰り返さないか確認する。
4. Tabで輪を出す。Spaceを押している間と、離した後を比べる。Enterでも操作回数が増えることを確認する。

## 完成条件

- `type="button"`のHTMLボタンを1つ作り、「押してみる」と表示する。
- 青`#2563eb`の面に白文字。文字14px・太さ600、面の高さ44px以上、左右の余白24px、角丸8pxを目安にする。
- 通常時は下に影がある。hoverとfocus-visibleでは青が少し濃くなる。重ねただけでは縮めない。
- 押している間だけ、面が中心から約96%に縮み、約2px下がり、影が浅くなる。押下時はさらに濃い青にする。影の数値の完全一致は不要。
- 縮小・移動・影・背景色を約120ms・ease-outで変化させる。離すと滑らかに通常状態へ戻る。ポインターやフォーカスが残っていれば、その状態の色に戻る。輪はアニメーションさせない。
- 外側の押せる範囲と周囲の配置は固定する。左右・下端で長押ししても反応が途切れず、クリックは1回につき操作回数が1増える。押しながら範囲外へ出て離した場合も、沈んだまま残らない。
- Tabで太さ3px・隙間3pxを目安とした青い輪がすぐ見える。Spaceの長押しでも輪が残る。Enter・Spaceでそれぞれ1回ずつ操作回数が増える。
- Spaceでは押している間の沈みと、離した後の復帰を確認する。Enterは操作できればよい。ブラウザによりEnterの押下表示は短いか、見えない場合がある。
- 360px・390px幅でも文字・ボタン・輪が欠けず、横にはみ出さない。hoverが使えなくても操作できる。
- 動きを減らす設定ではtransition・縮小・上下移動をなくす。影と背景色はすぐ切り替わり、押下が分かる。輪とボタン操作は保つ。
- 「大きさと影がどう変わり、なぜ沈んで見えたか」を一言説明する。

## 段階的に考える

まず通常時の面と影、次に押している状態、最後に行き帰りの変化を作る。前回と同じく、変形できる表示形式の内側要素を使い、外側のボタンで操作状態を受け取る考え方が役立つ。

今回の手がかりは`:active`、`transform`の縮小と移動、`box-shadow`。hover・focus-visibleと押下が同時に成立するとき、どの見た目を優先するかも考える。transitionは戻るときにも必要。

動きを減らす設定では、時間だけでなく変形そのものも止める。詰まったら、観察した現象を添えてヒントを求めてください。

## 自分の実装の確認

1. 通常・hover・長押し・離す、すばやい連打を試す。
2. 左右端・下端を長押ししてから離し、安定性と回数を確認する。押しながら範囲外へ出て離す操作も試す。
3. ポインターを外しTabで選ぶ。輪、Space長押しと復帰、Enter・Spaceの回数を確認する。Tabで離れると通常状態へ戻ることも見る。
4. 360px・390px幅で文字・輪の欠けとはみ出しを確認する。
5. OSまたは開発者ツールで「動きを減らす」を有効にし、変形せず影と色で反応することを確認する。確認後に設定を戻す。再現できなければ、CSS確認と実動作の未確認を区別して伝える。
6. 沈んで見えた理由を一言添えて「レビューして」と伝える。
