# Lesson 02: 枠線ボタン・テキストボタン

進捗: 完了（2026-10-26、レビュー済み）

## 到達点

- 枠線ボタンとテキストボタンを実装し、「保存する」を主役とする強弱を表現した。
- 枠線の太さを余白から引き、3つのボタンの高さを48pxに揃えた。
- テキストボタンにも上下左右の余白を設けた。
- 390px幅での折り返しと収まり、Tabによる移動と標準フォーカス表示、Enter・Spaceで再読み込みされないことを確認した。
- 型チェック・ビルド・静的検査を通過した。

次は下記の応用で長い文言の収まりを試し、Lesson 03で操作への反応を学ぶ。

## 目的

編集画面の操作を想定し、主役の「保存する」、補助の「下書き保存」、編集をやめる「キャンセル」を並べる。塗りつぶし・枠線・文字だけの見た目で、操作の強弱を表現する。

目安は30〜60分。第1回の塗りつぶしボタンを踏まえ、今回は2つのボタンを自分で実装する。

## 編集するファイル

- `OutlineTextButtonsExercise.tsx`: 案内文を「下書き保存」「キャンセル」の2つのボタンに置き換える。
- `OutlineTextButtonsExercise.css`: 各ボタンに専用のクラスを付け、見た目を整える。

`npm run dev`で開く第2回の「見本」と「あなたの実装」を比較する。「保存する」ボタンと、ボタンを並べて折り返す枠は準備済み。第1回のファイルや`src/reference/`は編集しなくてよい。実際の保存・キャンセル処理も不要。

## 観察するところ

- 3つのうち、最初に目が向く操作はどれか。
- 枠線ボタンと塗りつぶしボタンは、何を揃え、何を変えているか。
- テキストボタンは背景や枠がなくても、文字の周りにどのくらい押せる余白があるか。

## 完成条件

- HTMLの`button`要素を2つ使い、`type="button"`を指定する。
- 「下書き保存」は青い枠線と青い文字にし、背景は比較欄の色が見えるようにする。
- 「キャンセル」は枠線と塗りつぶしのない、落ち着いた色のテキストボタンにする。
- 2つとも、文字の大きさ・太さとボタン全体の高さを「保存する」に近づける。枠線の分も含めて高さを観察する。
- テキストボタンにも上下左右の余白を設け、文字の周りまで押せるようにする。
- 「保存する」が最も目立ち、「下書き保存」「キャンセル」の順に控えめに見える。
- 狭い画面で折り返しても、文字が欠けたり、比較欄からはみ出したりしない。
- ブラウザ標準のフォーカス表示を残し、Tabキーで選択位置が分かるようにする。

寸法をぴったり一致させることより、見比べて強弱と余白を調整できることを重視する。hover・押下・独自のフォーカス装飾は第3回で扱う。状態管理や共通部品化は不要。

## ブラウザでの確認

1. 2つのファイルを保存し、比較欄への反映を確認する。
2. 3つのボタンの目立ち方、文字、余白、高さを見比べる。
3. 画面幅を390px程度まで狭めて、折り返しと収まりを確認する。
4. Tabキーで順に選択でき、Enter・Spaceで操作しても再読み込みされないことを確認する。
5. 「なぜ下書き保存を枠線にし、キャンセルを文字だけにしたか」を短く説明し、「レビューして」と伝える。

## レビュー後の応用

枠線ボタンの文言を「下書きとして保存」に変え、長い文字でも余白と高さが保たれるか試す。
