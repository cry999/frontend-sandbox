## 目的

CSSのtransitionで、背景色が切り替わるまでの変化を作る。ポインターを重ねたときだけでなく、離したときにも滑らかに戻るようにする。時間と速度曲線を別々に変え、印象の違いを言葉にする。

`npm run dev`で表示されたローカルURLを開く。画面上部の今回の課題で、見本と自分の実装を比較する。基礎編の6課題は下の折りたたみから確認できる。

## まず観察する

1. 基本の見本にポインターを重ね、濃い青になるまでを見る。離して、青に戻るまでを見る。変化の途中で出入りしたらどうなるかも試す。
2. 「時間と速度曲線を比べる」を開く。基本の300ms・easeと150ms・easeを比べる。どちらが素早く感じるか。
3. 基本の300ms・easeと300ms・linearを比べる。同じ所要時間でも、途中の進み方に違いを感じるか。
4. Tabで基本の見本を選ぶ。色が変わり、輪がすぐに出ることを確認する。Enter・Spaceでも押せることを試す。

基本の見本、比較用の2つ、実装欄の操作回数は、それぞれの枠で数える。ボタンを押した結果を確かめる土台なので、カウンターや状態管理を自分で実装する必要はない。

## 完成条件

- `type="button"`のHTMLボタンを1つ作り、ラベルを「続ける」にする。
- 通常の背景は青`#2563eb`、hoverとキーボードフォーカス時は濃い青`#1e40af`。白い文字を使い、変化の途中も読めるようにする。
- 高さ44px以上、文字14px・太さ600、左右の余白24px、角丸8pxを目安にする。色の変化でボタンの位置や大きさが動かない。
- 背景色だけを約300ms・easeで滑らかに変える。hoverを外したとき、キーボードフォーカスを外したときにも滑らかに通常色へ戻る。
- Tabで太さ3px・隙間3pxを目安とした青い輪がすぐに出る。輪自体はアニメーションさせない。Enter・Space・クリックで操作回数が1ずつ増える。
- 360px・390px幅でも文字・ボタン・輪が欠けず、横にはみ出さない。
- 動きを減らす設定では色がすぐ切り替わり、輪とクリック・キーボード操作はそのまま使える。
- 時間と速度曲線をそれぞれ一度変えて試し、違いを一言ずつ説明する。最後は300ms・easeに戻す。比較用ボタンを実装側に増やす必要はない。

## 段階的に考える

まずは基本のボタンと通常時の見た目を作り、次にhoverとフォーカス時の色を決める。色が切り替わることを確認できたら、切り替わり方を調整する。

今回初めて使うtransitionは、状態が変わる前後の値を一定時間でつなぐ仕組み。考える項目は「何を変えるか」「何秒かけるか」「途中をどんな速さで進めるか」の3つ。`300ms`は0.3秒。`ease`は途中で進む速さが変わり、`linear`は一定のペースで進む。

戻るときだけ急に切り替わる場合は、ポインターを離した後にも変化の指定が効いているかを確認する。すべてのプロパティを一括で変化させず、背景色に絞って考える。

動きを減らす設定は、CSSの`prefers-reduced-motion`で受け取れる。値が`reduce`のときに、今回の色の変化にかける時間をなくす。画面全体や過去の課題ではなく、今回のボタンだけに適用する。必要なら「動きを減らす設定のヒント」と伝えてください。

## 自分の実装の確認

1. hoverで濃い青へ変わり、離すと青へ戻る様子を見る。途中で何度か出入りしても位置やサイズが変わらないか確認する。
2. Tabで実装側へ移動し、輪がすぐに見えるか確認する。Enter・Spaceでそれぞれ1回ずつ操作回数が増えるかを見る。見本側の回数は変わらない。
3. 360px・390px幅で確認する。タッチでhoverが使えない場合も、押す操作に困らないことを確認する。
4. OSのアクセシビリティにある「動きを減らす」を有効にするか、ブラウザの開発者ツールで`prefers-reduced-motion: reduce`を再現する。色がすぐ切り替わり、輪と操作回数は使えるかを確認し、確認後に設定を戻す。
5. 時間だけ、速度曲線だけを変えて違いを観察し、300ms・easeへ戻す。
6. 「時間を変えるとどう感じたか」「速度曲線を変えるとどう感じたか」を添えて「レビューして」と伝える。

## 準備時の確認

- ビルド・静的検査は通過。
- ブラウザで見本を表示し、Tabでの移動、3pxの輪、Enter・Space・クリックによる操作回数の増加を確認。実装欄の回数が変わらないことも確認。
- 見本の高さ44px、hover時と通常時の背景色、基本と比較用のtransition指定をブラウザ上で確認。戻る動きの時間と速度曲線はコードで確認した。途中の色を時系列で計測する確認は未実施。
- 360px・390px幅で、横はみ出しがなく、比較用の見本と輪が収まることを確認。
- 動きを減らす場合は、全3種類の見本でtransitionをなくすCSSを確認。使用できるブラウザ操作には設定の再現機能がなく、別ブラウザへのアクセスも許可されなかったため、設定を有効にしたブラウザ実測は未確認。ユーザー実装のレビュー時に改めて確認する。
