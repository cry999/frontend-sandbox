# アニメーション05：下線が伸びるボタン

進捗：準備完了・実装待ち。全30問の第5問。目安30〜60分。

## 目的

疑似要素で装飾の下線を作り、変形の起点によって伸びる方向を決める。ボタンと文字の位置を固定したまま、下線だけで操作への反応を伝える。

前問はレビュー合格（2026-10-29、合格コミット `8270424`）。矢印だけの動きは控えめで気づきづらい、という観察があった。今回は文字の幅全体へ伸びる線の見え方を観察する。

## 編集するファイル

- `Animation05UnderlineExercise.tsx`：案内文を「詳しく見る」のHTMLボタンに置き換える。
- `Animation05UnderlineExercise.css`：今回専用のクラスで見た目・状態・下線の動きを作る。

このREADMEと上記2ファイルは同じフォルダにある。見本は `src/reference/` に分離済み。枠組み・見本・過去の課題は編集不要。ひな形には解答を入れていない。ライブラリ追加、状態管理、操作回数の実装は不要。

開発サーバーの画面は [localhost:5173](http://localhost:5173/)。上部に今回の比較画面、下の折りたたみに過去の課題がある。

## まず観察する

1. ポインターを重ね、下線の左端と右端のどちらが動くか見る。
2. 離すと下線がどちらへ縮むか見る。途中で重ね直す操作も試す。
3. Tabで選び、下線とフォーカスの輪を確認する。Tabで離れるとどう戻るか見る。
4. 文字の周りの余白にも重ねる。反応する範囲が文字だけに限られないことを確認する。

## 完成条件

- `type="button"` のHTMLボタンを1つ作る。ラベルと読み上げ用の名前は「詳しく見る」。下線は文字や別のHTML要素を増やさず、疑似要素で作る。
- 背景は透明、文字は青 `#2563eb`、14px・太さ600・行高20px。高さ48px以上、左右の余白24px、角丸8pxを目安にする。
- 下線は文字の幅と同じ長さ、太さ2px。文字を囲む20pxの行ボックスの下端から4px下を目安に置く。通常時は見えない。
- hoverとfocus-visibleで下線が左から右へ伸び、文字幅いっぱいになる。離れると右端が左へ戻って消える。左右とも左端を固定し、約220ms・ease-outで伸縮する。途中で重ね直しても急に飛ばない。
- 動きは横方向の変形で作る。ボタン全体・文字・周囲の配置は動かさず、押せる範囲や幅・高さを変えない。
- hoverとfocus-visibleでは文字と線を濃い青 `#1d4ed8` にする。押下中はさらに濃い青 `#1e40af`。色のアニメーションは不要。フォーカスが残っている間は下線を保つ。
- Tabで太さ3px・隙間3pxの青い輪をすぐ表示する。輪はアニメーションさせず、Spaceを押している間も保つ。
- 文字上と左右の余白で、クリック1回につき操作回数が1増える。Enter・Spaceも各1回反応する。押したまま外へ出て離しても押下色が残らない。
- 360px・390px幅で文字・下線・輪が欠けず、横にはみ出さない。hoverが使えなくても操作できる。
- 動きを減らす設定では下線を伸縮させず、hover・focus-visibleに合わせて全長の線をすぐ表示・非表示にする。色・輪・操作を保つ。
- 「左端を起点にすると、どんな印象になるか」を一言説明する。

## 段階的に考える

最初に通常のボタンと文字を整える。次に疑似要素で静止した下線を作り、文字との間隔を決める。最後に表示状態と変形の起点、行き帰りの時間を調整する。詰まったら、見えている現象を添えてヒントを求めてください。

## 自分の実装の確認

1. 重ねる・離す・途中で重ね直す操作で、伸縮の方向と文字・ボタンの位置を見る。
2. 文字上と左右の余白をクリックして回数を見る。押したまま外へ出て離す操作も試す。
3. ポインターを外し、Tabで選ぶ。輪と下線、Enter・Spaceの回数、Space長押し中の色と離した後の復帰を見る。
4. 360px・390px幅で欠けや横はみ出しを確認する。
5. OSや開発者ツールで動きを減らす設定を有効にして確認し、確認後は戻す。再現できなければ、CSS確認と実動作の未確認を区別して伝える。
6. 動きの印象を一言添えて「レビューして」と伝える。

## 準備時の確認

- ビルド・静的検査は通過（2026-10-29）。
- ブラウザでボタン118×48px、文字70×20pxを確認。hoverで下線が全長になり、hoverとフォーカスを外すと消える。左端の起点、220ms・ease-outの指定を確認。全フレームの時系列計測は未実施。
- Tabで太さ3px・隙間3pxの輪を表示し、下線が出ることを確認。Enter・Spaceは各1回反応。文字上と左右の余白のクリックも各1回反応した。
- 押したまま外へ移動して離しても操作回数が増えず、押下状態が残らないことを確認。操作前後のボタンは118×48px。フォーカスが残る場合は下線も保たれる。
- 360px・390px幅で文字・下線・輪に欠けがなく、ページに横はみ出しがないことをブラウザで確認。実装欄は案内文のみで、回数は0。
- 動きを減らす場合にtransitionと伸縮を止め、全長の下線を即時切り替えるCSSを確認。利用可能なブラウザ操作には設定の再現機能がなく、有効時の実動作は未確認。Space長押し中の表示もレビュー時に改めて確認する。
