# Lesson 04: アイコン付き・アイコンのみのボタン

進捗: 準備完了・実装待ち（2026-10-26）

## 目的

「＋ 追加する」と、点が3つ並ぶ「その他の操作」の2種類を作る。アイコンと文字の配置、間隔、小さなアイコンでも押しやすい範囲、読み上げ用の名前を学ぶ。目安は30〜60分。

## 編集するファイル

- `IconButtonsExercise.tsx`: 案内文を2種類のボタンに置き換える。
- `IconButtonsExercise.css`: 第4回専用のクラスを使って装飾する。

`npm run dev`で第4回の「見本」と「あなたの実装」を比較する。第3回の自分の実装を参考にしてよい。過去の課題・見本・画面の枠組みは編集不要。

アイコン素材は`../../icons/ButtonIcons`から`AddIcon`と`MoreIcon`を読み込める。それぞれを`<AddIcon />`、`<MoreIcon />`として配置する。素材は20×20pxで、色は周囲の文字色に合わせて変わる。装飾用なので、素材自体は読み上げない設定を済ませてある。ボタンに名前を付けるのは今回の課題。

2つのボタンの間隔は比較画面の枠が12pxに整える。操作回数も枠が数えるため、クリック処理・メニューの開閉・実際の追加処理・状態管理・共通部品化は不要。

## 観察するところ

- アイコンと文字の縦方向の中心は揃っているか。どのくらい離れているか。
- 点が3つだけのボタンでも、押せる四角い範囲はどれくらいあるか。
- ボタンの端の余白をクリックしても反応するか。
- 見た目に文字がない「…」を、読み上げでは何と呼べば操作の意味が分かるか。

## 完成条件

- 両方ともHTMLの`button`要素を使い、`type="button"`を指定する。
- 「追加する」は青い背景・白い文字で、左に`AddIcon`、右に文字を置く。縦方向の中心を揃え、間隔は8pxを目安にする。
- 「追加する」の文字は16px・太さ600・行の高さ1.5、高さ48px、左右の余白20px、角丸8pxを目安に整える。
- アイコンのみのボタンは`MoreIcon`を中央に置く。幅・高さとも48px、角丸8px、青い1pxの枠線、透明な背景・青いアイコンにする。枠線を含めて48pxに収める。
- 20pxのアイコンの外側も含め、48pxのボタン全体をクリックできる。
- アイコンのみのボタンに「その他の操作」という読み上げ用の名前を付ける。`aria-label`などを使い、`title`だけには頼らない。「追加する」は見える文字が名前になる。
- 第3回で学んだhover・押下・指差しカーソル・`focus-visible`の輪を両方に付ける。押下時は周囲の配置を動かさず1px下がり、離すと戻る。
- Tabで2つを順番に選べる。クリック・Enter・Spaceで操作回数が1回ずつ増え、Tabだけでは増えない。
- 390px程度の画面幅でも、アイコン・文字・輪が欠けず、横にはみ出さない。

見本の塗りつぶしは通常`#2563eb`、hover`#1d4ed8`、押下`#1e40af`。枠線ボタンは枠と文字が`#2563eb`、hover背景`#eff6ff`、押下背景`#dbeafe`。輪は青色で太さ3px・隙間3px。色の完全一致より配置と押しやすさを重視する。

## ブラウザでの確認

1. アイコンと文字の中心、8px程度の間隔、2種類のボタンの高さを見本と比べる。
2. アイコンそのものに加え、ボタンの端の余白もクリックし、操作回数が増えることを確認する。
3. hover・押下・離した後の見た目を確認する。
4. Tab・Shift+Tabで移動し、両方に輪が出ることを確認する。EnterとSpaceでも各1回増えるか試す。
5. 開発者ツールのアクセシビリティ情報で、役割がbutton、名前が「追加する」「その他の操作」になるか確認する。可能ならVoiceOverなどでも読み上げを聞く。
6. 390px程度の幅にして、文字・アイコン・輪の収まりを確認する。
7. 「アイコンより大きい押せる範囲が必要な理由」「文字のないボタンに名前を付ける理由」を短く説明し、「レビューして」と伝える。

## 準備時の確認

ビルド・静的検査は通過。ブラウザで2種類の見本の表示、高さ48px、アイコンのみのボタンの幅48px、アクセシビリティ上の名前、クリック・Enter・Spaceの回数加算、Tab・Shift+Tabによる移動と輪を確認済み。390px幅でも横にはみ出さず、比較欄とボタンが収まることを確認した。音声による読み上げ自体は未確認。ユーザーの実装のレビューとは区別する。

## レビュー後の応用

「追加する」を「項目を追加する」に変える。文字が長くなっても、アイコンとの間隔と左右の余白、高さが保たれるか試す。
