# アニメーション04：矢印が進むボタン

進捗：レビュー合格（2026-10-29）。全30問の第4問。目安30〜60分。

## 到達点

- HTMLボタン内に文字と装飾用の矢印を分け、hover・focus-visibleで矢印だけを右へ6px動かした。文字と面の位置・寸法、押せる範囲を維持した。
- 間隔12px、矢印20px、ボタン136×45px。spanとflexでSVGの下の余白をなくし、縦の中心を揃えた。
- ボタンと矢印のtransitionを200ms・ease-outに指定し、通常位置へ復帰することを確認。前回の指摘は、軽減設定でも変形が残る点、距離・間隔・速度曲線、divとSVG下の余白。修正後、矢印側のease-outの指定漏れも解消した。
- Tabの3pxの輪と3pxの隙間、Enter・Spaceで各1回反応、Space長押し中の輪・矢印位置の維持と押下色・復帰を確認。
- 文字上・矢印上・左右端のクリックは各1回反応。押したまま範囲外へ出て離すと回数は増えず、押下色も残らない。フォーカスのないhoverでも6px進み、外へ離れると復帰する。
- 360px・390px幅で文字・矢印・輪の欠けと横はみ出しなし。ビルド・静的検査は通過。
- 動きを減らす場合はtransitionと移動をなくし、色と輪を保つCSSを確認。ブラウザにも条件が認識されている。利用可能な操作では設定を再現できず、有効時の実動作は未確認。全フレームの時系列計測は未実施。
- ユーザーの観察：「面白いなと思いましたが、ボタン自体が動かないと印象薄くて気づきづらかった」。動く範囲が小さいと控えめになり、進む方向へ注意を向ける演出になると整理した。
- ユーザーからtransitionを複数箇所に書く場合の指定漏れ対策について質問。変化するプロパティは要素ごと、時間・速度曲線は共通のルールまたはCSS変数へまとめる方法を案内。実装の整理は合格条件外で、代理修正はしていない。
- 任意の応用：距離だけを3pxにして6pxと比べ、最後に戻す。次はアニメーション05「下線が伸びる」で疑似要素と変形の起点を学ぶ。

## 目的

ボタンと文字の位置を固定し、内部の矢印だけを動かして「先へ進む」印象を作る。前問で学んだ、操作を受け取る要素と動かす要素を分ける考え方を使う。

前問はレビュー合格（合格コミット`83bfe64`）。「遠近法？」という観察から、縮小と浅い影によって沈んで見える理由を整理した。今回は動かす対象と方向に注目する。

## まず観察する

1. 見本へポインターを重ね、矢印・文字・青い面のどこが動くか見る。
2. ポインターを離して、矢印が戻る動きを見る。途中で重ね直した場合も試す。
3. Tabで選び、輪と矢印を見る。次の場所へTabで移るとどう戻るか確認する。
4. 矢印が進んだ状態でクリックする。文字と矢印のどちらの上からでも操作できることを確かめる。

## 完成条件

- `type="button"`のHTMLボタンを1つ作り、「次へ進む」と右矢印を横に並べる。読み上げ用の名前は「次へ進む」とし、矢印は装飾として扱う。
- 青`#2563eb`の面に白文字。文字14px・太さ600、高さ44px以上、左右の余白24px、角丸8px、文字と20pxの矢印の間隔12pxを目安にする。縦の中心を揃える。
- hoverとfocus-visibleで背景が濃い青`#1d4ed8`になり、矢印だけが通常位置から右へ約6px進む。文字・面・押せる範囲・周囲の配置は動かさず、ボタンの幅も変えない。
- 矢印の移動と背景色を約200ms・ease-outで変える。通常時にも戻る動きがあり、途中で重ね直しても急に飛ばない。フォーカスが残っている間は矢印が進んだ状態を保つ。
- 押している間は背景をさらに濃い青`#1e40af`にする。矢印に追加の移動や縮小は不要。離すと、そのときのhover・focus-visibleの状態に戻る。
- Tabで太さ3px・隙間3pxを目安とした青い輪をすぐ表示する。輪はアニメーションさせず、Spaceで押している間も保つ。
- 文字上・矢印上・左右端でクリックしても1回につき操作回数が1増える。Enter・Spaceでも各1回増える。押したまま外へ出て離しても押下色が残らない。
- 360px・390px幅で文字・矢印・輪が欠けず、横にはみ出さない。hoverが使えなくても操作できる。
- 動きを減らす設定ではtransitionと矢印の移動をなくす。hover・focus-visible・押下の背景色はすぐ切り替わり、輪と操作を保つ。
- 「矢印だけを動かすと、ボタン全体を動かす場合と印象がどう違うか」を一言説明する。

## 段階的に考える

まず通常時の文字と矢印を並べる。次に、ボタンの状態をきっかけに内部の矢印だけが変化するようにする。最後に行き帰りの時間と、動きを減らす場合を確認する。

矢印そのものにポインターを重ねたときだけ反応する構造になっていないか、観察してみよう。矢印が変形できる表示形式かどうかにも注目する。詰まったら、見えている現象を添えてヒントを求めてください。
