# Frontend Sandbox

ボタンの実装を通じてUIデザインを学ぶ練習用プロジェクトです。React、TypeScript、Viteと通常のCSSを使います。

## はじめる

初期化時の動作確認環境はNode.js 26.8.1、npm 12.0.2です。使用するNode.jsの対応範囲はViteの依存パッケージに従います。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLを開いてください。見本と自分の実装が並び、ファイルを保存すると表示が更新されます。

## 最初に編集する場所

- [BasicButtonExercise.tsx](src/exercises/01-basic-button/BasicButtonExercise.tsx)
- [BasicButtonExercise.css](src/exercises/01-basic-button/BasicButtonExercise.css)

課題の内容は[Lesson 01](src/exercises/01-basic-button/README.md)、全体の流れは[練習プラン](practice/plan.md)にあります。最初の実装欄は空欄です。見本を観察して、自分でボタンを書いてください。

## 確認コマンド

```sh
npm run build
npm run lint
```
